---

## บั๊กหลัก — ทำไมแผง admin ขึ้น "—" ตลอด

`app.py` ไม่เคยให้จอ admin `join_room(code)` เลย
แต่ event `room` / `tick` / `round_end` ส่งแบบ `to=room.code`

→ **จอ admin ไม่เคยได้รับ event เหล่านั้นสักตัว** ทั้งที่ห้องทำงานปกติทุกอย่าง

## บั๊กที่สอง — ทำไมกรอกรหัสแล้วเข้าไม่ได้

- `app.py __main__` สร้างห้องหนึ่ง แล้วพิมพ์รหัสลง console
- จอ admin `create_room` สร้าง **อีกห้องหนึ่ง** ทุกครั้งที่เชื่อมต่อ

→ รหัสบน console กับรหัสบนจอเป็นคนละห้อง แถม refresh ทีก็เปลี่ยนอีก
→ เด็กกรอกรหัสไหนก็ผิดสักทาง

แก้ด้วย `Rooms.primary()` — บูธมีห้องหลักใบเดียว รหัสไม่เปลี่ยนเอง
`create_room` ตอนนี้ต้องมีรหัส admin และเป็นการ *ย้ายห้อง* ไม่ใช่สร้างซ้อน

## สิ่งที่เพิ่ม

### 1. แผง admin ตามสเปก §7 — `templates/admin.html` เขียนใหม่ทั้งไฟล์
- **ประตูรหัสผ่าน** ก่อนเข้า (เดิมเปิด `/admin` ตรงๆ ได้เลย ใครก็กดรีเซ็ตได้)
- **ซ้าย = เกมสด · ขวา = แผงควบคุม**
- ปุ่มสลับ 3 โหมดฝั่งซ้าย:

| โหมด | ทำอะไร |
|---|---|
| **รหัสห้อง** | รหัสตัวใหญ่ + URL + ข้อความ GMN (จอดึงเด็ก) |
| **ดูเกมสด** | ดูเกมที่เด็กกำลังเล่นอยู่ ไม่กินสล็อต |
| **เล่นเอง** | admin ลงเล่นในห้องแยก คะแนนลงบอร์ด ADMIN |

- แถบสถานะทับล่างจอ เห็นรหัสห้อง/ทีม/คะแนน/เวลาตลอดแม้กำลังเล่น

### 2. โหมด spectate (`?spectate=1`)
- socket event ใหม่ `spectate` → เข้า socket room โดยไม่กินสล็อต
- ได้ `schedule` เดียวกับผู้เล่นเป๊ะ → เห็นอุกกาบาตดวงเดียวกัน เวลาเดียวกัน
- ยิงไม่ได้ กันไว้ทั้งฝั่ง client และ server
- ปุ่มยิงซ่อน · นาฬิกาโชว์ · การ์ด GMN ย่อให้พอดีครึ่งจอ

### 3. `?code=HT037` ใน URL
เข้าห้องอัตโนมัติ ไม่ต้องพิมพ์ — จอ admin ใช้ส่งรหัสให้ iframe

### 4. ห้องกลับ lobby เองหลังจบรอบ (25 วิ)
เดิมห้องค้างสถานะ `ended` ตลอด
ตอนนี้ล้างชื่อทีม + คนที่ออกไปแล้วด้วย ไม่งั้น**กลุ่มถัดไปกลายเป็นชื่อทีมของกลุ่มก่อน**
(เจอตอนเทสจริง ไม่ได้คิดเอาเอง)

### 5. บอร์ด ADMIN ใช้งานได้จริง
`is_admin_room` เดิมถูกอ่านใน `_finish_round` แต่**ไม่เคยถูกตั้งค่าที่ไหนเลย**
→ บอร์ด ADMIN ว่างตลอดกาล ตอนนี้ `rooms.admin_room()` ตั้งให้ตอนสร้าง

## ผลเทสจริง (รันจริง ไม่ได้เดา)

```
admin_hello True HT434          ← admin ได้รหัสห้องหลัก
room_created HT810              ← ปุ่มห้องใหม่
joined slot 1 needTeam True     ← เด็กเข้าห้องได้
team_set ALPHA
round_start n=20                ← ตารางส่งถึงทั้งผู้เล่นและคนดู
storm meteor hp: 3
destroyed: [1, 2, 3, 12]        ← ดวงปกติ 1 นัดแตก
damaged: [(12,1,3), (12,2,3)]   ← ดวงพายุ 3 นัดถึงแตก
tracebacks in server log: 0
```

GMN ที่ส่งถึง client จริง:
```
duration 1.45 · detectedByText 'Chile' · altDeg 32.297 · azDeg 66.879
```

HTTP 200 ทั้งหมด: `/` · `/admin` · `/play?spectate=1` · `/api/leaderboard` · `/api/gmn/stats`

ลูป lobby: `team after reset: None · state: lobby · players: 0` ✓

## ยังไม่ได้ทำ (ค้างจาก ORDER.md)

- **F8 เส้นสามเหลี่ยม** — ยังไม่มีในโค้ดเลย
- **F9 deploy + เทส restart** บน hoster จริง
- `src/meteors.js` ยังใช้ชื่อ `yawImpact` / `distImpact` และมีคอมเมนต์เก่าว่า
  *"รายการดวงที่เพิ่งตกใส่เมือง (main เอาไปหัก HP)"*
  พฤติกรรมถูกแล้ว แต่ชื่อกับคอมเมนต์ยังเป็นของเดิม
  → **เสี่ยงให้ session หน้าดริฟต์กลับไปทำให้ตกใส่เมืองอีก** ควรเปลี่ยนเป็น `yawEnd` / `distEnd`
- `src/main.js` (โหมดคนเดียวเดิม) ไม่มีเฟสพายุ — ต้องตัดสินใจว่าเก็บเป็นโหมดซ้อมหรือลบทิ้ง

## ที่อยากให้ดูตอนเทสจริง

`SPAWN_RATE_PER_MIN = 10` คูณจำนวนคน

- ทีม 1 คน → อุกกาบาตดวงละ ~6 วินาที **ค่อนข้างเหงา**
- ทีม 3 คน → ~2 วินาที/ดวง กำลังดี

ถ้าลองเล่นคนเดียวแล้วรู้สึกว่าง ปรับตัวเลขนี้ตัวเดียวใน `game/config.py`
ไม่ต้องแตะอย่างอื่น
